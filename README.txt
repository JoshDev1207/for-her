TULIPS, FOR YOU
==============

OPEN THE WEBSITE
1. Extract the entire ZIP file first.
2. Open the tulips-for-you folder.
3. Open standalone.html in a web browser. It is the complete website in
   one file, with the pictures and fonts embedded. This is the easiest
   copy to move between devices.

The regular index.html version is also included with editable source
files. Open index.html if you customize message.js.

All images and fonts are included. No installation, account, server, or
internet connection is needed to view the website. The art-credit links
are external websites and need internet if you choose to open them.

Tap "There's a note for you" or the little gift tag to read the letter.
Tap the capybara holding a heart for little surprise messages.
Close the letter with its Close button, Escape, or a click outside it.

PERSONALIZE IT (OPTIONAL)
Open message.js in a text editor (Notepad or VS Code).
Change recipient, signature, and the four paragraphs, then save.
Keep the quotation marks and commas. Refresh index.html to see your changes.
For example, recipient can be her name and signature can be your name.
standalone.html is a separate ready-to-share copy. To personalize that
copy, open it in a text editor and find window.BOUQUET_MESSAGE near the
end of the file; edit its recipient, signature, and paragraphs there.

SHARE IT
Send the ZIP and ask her to extract it before opening standalone.html in
a web browser. Some phone file-preview apps do not run website scripts;
use a browser, or use a hosted link. To make a link that opens easily on
a phone, upload the contents
of the tulips-for-you folder to a static website host. This ZIP is the
complete website; it has not been published to a public URL.

FILES
standalone.html - complete website with all images, fonts, and code embedded
index.html   - page, paper-wrap artwork, and default letter
styles.css   - responsive layout and colors
message.js   - your editable love note
script.js    - note and capybara interactions
assets/      - local tulip photo, stickers, fonts, and font licenses
CREDITS.txt  - online image sources and usage terms

Keep the assets folder and the other files together.
The design adapts to phone, tablet, and desktop screens.
The flowers are photographic cutouts and remain still.
This is a personal gift; the tulip asset has a non-commercial license.
